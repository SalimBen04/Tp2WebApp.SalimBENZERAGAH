Lors du lancement de mon application sur le serveur Payara, j'ai rencontré une erreur HTTP 500 liée à l'absence de la variable GEMINI_KEY lors de l'initialisation du composant LlmClient. Cette erreur venait du fait que mon code cherchait la clé d'API uniquement dans les propriétés JVM (System.getProperty), alors que je l'avais configurée dans les variables d'environnement de mon système d'exploitation. Pour résoudre le problème proprement, j'ai adapté la méthode d'initialisation afin d'inspecter d'abord les variables d'environnement avec System.getenv("GEMINI_KEY"), puis d'utiliser les propriétés JVM en recours. Après avoir redémarré IntelliJ et le serveur Payara, la clé a été correctement détectée, ce qui a permis d'instancier l'assistant LangChain4j et de valider les échanges avec l'API Gemini.
